# Potter-Verse

An unofficial, fan-made tribute site exploring the Harry Potter series — built as a front-end practice project around book summaries, house profiles, and a short interactive sorting quiz.

**Live demo:** _add your GitHub Pages / hosting link here_

## About

This project replaces an earlier version that reused official book cover art, promotional trailer clips, and hosted downloadable book files. This rebuild is a from-scratch, original implementation:

- All book and house descriptions are written for this project.
- All visuals (emblems, shields, backgrounds) are drawn with plain CSS/SVG — no scanned pages, cover art, or official logos/crests.
- The sorting quiz's questions, scoring, and results are entirely original and unaffiliated with any official questionnaire.
- No PDFs or copyrighted video are hosted anywhere in this repository.

## Tech stack

- HTML5, CSS3 (custom properties, grid/flexbox, CSS-only starfield & gradient animations)
- Vanilla JavaScript (no frameworks) for the interactive quiz
- Google Fonts (Cinzel, Crimson Text)
